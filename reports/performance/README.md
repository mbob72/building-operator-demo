# Сырые результаты performance benchmark

Файлы в этом каталоге генерируются командой `npm run test:performance`. Каждый JSON соответствует
одной комбинации fixture (`representative` или `stress`) и browser profile (`desktop-chromium` или
`mobile-chromium`). Итоговая интерпретация и зафиксированные ограничения находятся в
`reports/performance.md`.
